# Portfolio Online — นายณัฐวุฒิ จัดตาดี

เว็บไซต์แบบ Static พร้อมนำขึ้น GitHub Pages

## วิธีใช้
1. สร้าง Repository ใหม่ใน GitHub เช่น `nattawut-portfolio`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ไปที่ root ของ repository
3. ไปที่ Settings > Pages
4. Source เลือก Deploy from a branch, Branch `main`, Folder `/ (root)` แล้ว Save
5. รอสักครู่ GitHub จะแสดง URL เว็บไซต์

ไฟล์หลัก: `index.html`, `style.css`, `script.js`
